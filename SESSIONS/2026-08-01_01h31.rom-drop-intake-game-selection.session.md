# Session: ROM Drop Intake Options for Selected Games

Date: 2026-08-01 01:31

## Objective
When a ROM file is dragged and dropped while a game is selected, identify the file using the catalogue and present the same intake choices ("Como [Juego]" vs "Tal cual") as when a folder is selected.

## Context & Root Cause
In `src/views/ROMExplorer.tsx`:
- The function `openDrop` determines whether to query the catalogue (`RomIntakeService.identify`) via the variable `askable`.
- `askable` was restricted to `destination.target.kind === 'folder' && files.some((file) => !isImageName(file.name))`.
- Consequently, dropping ROMs while a game is selected (`target.kind === 'game'`) skipped identification, resulting in an undefined `intake` payload and causing `MediaDropModal` to only show the "Copy as is" option.

## Proposed Changes

1. **`src/views/ROMExplorer.tsx`**:
   - Update `askable` in `openDrop` so that any drop containing non-image files (`files.some((file) => !isImageName(file.name))`) queries the catalogue regardless of whether the target is a folder or a selected game.
   - Update documentation comments in `openDrop` to reflect that non-image ROM drops identify games for both folder and game selections.

2. **Verification**:
   - Run the full test suite (`npx vitest run`) to ensure no regressions.
   - Confirm drag and drop handling correctly populates `intake` for non-image files when target is `'game'`.
