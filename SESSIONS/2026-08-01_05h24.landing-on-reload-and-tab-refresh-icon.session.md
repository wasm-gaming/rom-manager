# Landing View On Reload And Tab Refresh Icon

**Date:** 2026-08-01 05:24
**Topic:** Show initial landing view on page reload instead of "Carpeta recordada" and replace tab lock icon with a refresh icon.

## Context

When reloading the application with remembered tabs, `activeOrigin.locked` is `true`. Previously, `ROMExplorer` initialized `showLanding` to `false`, rendering `<div class="empty-state-full">` displaying "Carpeta recordada: [Nombre]" and a button to re-authorize. Additionally, locked/remembered tabs displayed a `<LockIcon />`.

The user wants:
1. On reload, eliminate the "Carpeta recordada: ..." view and show the initial landing page (`WelcomePanel`) instead.
2. In header remembered tabs, replace the lock icon with a refresh icon (`<RefreshIcon />`).

## Planned Changes

- **Create `RefreshIcon`**: Add SVG refresh icon component in `src/components/icons.tsx`.
- **Update `Tabs.tsx`**: Replace `LockIcon` with `RefreshIcon` for locked/remembered tabs.
- **Update `ROMExplorer.tsx`**:
  - Initialize `showLanding` state to `true` (default state).
  - Remove the locked state card `<div class="empty-state-full">` and render `<WelcomePanel>` when `showLanding` is `true` or when no node is active/unlocked.
  - Selecting a remembered tab in the header triggers `handleSelectOrigin`, prompting browser access and unlocking the folder.
