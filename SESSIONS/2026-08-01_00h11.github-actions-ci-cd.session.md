# GitHub Actions CI/CD

**Date:** 2026-08-01 00:11
**Status:** Planning

## Context

Implement GitHub Actions workflows for `rom-manager`, modeled after
`smbros-wasm/.github/workflows/` but adapted to the rom-manager stack:

- **Preact + Vite** app (no Godot, no WASM export)
- Two build outputs: `dist-app/` (Vite app) and `dist/` (tsup library)
- Scripts: `type-check`, `lint`, `test`, `build` (app), `build:lib` (library)
- Package scoped as `@rom-manager/editor`

## Reference workflows (smbros-wasm)

| Workflow | Trigger | Purpose |
|---|---|---|
| `build.yml` | push to main, tags, dispatch | Build SDK + WASM, deploy to GH Pages, attach release artifacts |
| `release.yml` | manual dispatch (bump choice) | Validate, build, npm version bump, npm publish, GH Release |

## Planned workflows for rom-manager

### 1. `build.yml` — CI + Pages deploy

- **Trigger:** push to `main`, tags `v*`, `workflow_dispatch`
- **Jobs:**
  - `validate` — lint, type-check, test
  - `build` — `npm run build` (app) + `npm run build:lib` (library)
  - `pages` — deploy `dist-app/` to GitHub Pages (on `main` only)
  - `release` — attach archives to GitHub Release (on tags only)

### 2. `release.yml` — npm publish

- **Trigger:** `workflow_dispatch` with `bump` input (patch/minor/major)
- **Jobs:**
  - Single job: validate → build:lib → npm version bump → npm publish → push tag → GH Release

## Implementation — 2026-08-01 00:13

### Files created

- `.github/workflows/build.yml` — CI workflow (lint, type-check, test, build app + lib, upload artifacts). Runs on push to `main`, tags `v*`, and `workflow_dispatch`.
- `.github/workflows/release.yml` — Release workflow (validate, build, npm version bump, npm publish with OIDC provenance, GitHub Release with archives, GitHub Pages deploy from `dist-app/`). Manual dispatch with bump choice, guarded to `main` only.

### Key decisions

- `build.yml` uses `concurrency: ci-${{ github.ref }}` with `cancel-in-progress: true` for fast feedback on pushes.
- `release.yml` uses `concurrency: release` with `cancel-in-progress: false` to prevent partial releases.
- Pages deploy is in `release.yml` only (per user request), using the `production` environment.
- Release archives bundle both `dist-app/` (Vite app) and `dist/` (tsup library) into a single `rom-manager/` folder.
- npm scope set to `@rom-manager` matching the package name.
