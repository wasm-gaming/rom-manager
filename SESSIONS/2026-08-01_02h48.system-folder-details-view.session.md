# 2026-08-01 02:48 - Display System Logo, Details, and Extension Info when Folder is Selected

## Summary
Replace the generic `Select a ROM to view its details` placeholder in `.details-pane` when a folder (or system) is selected with a dedicated System Details view featuring:
- A representative vector logo / badge for each system.
- Comprehensive system metadata (Full Name, Manufacturer, Release Year, Media Type).
- Detailed overview description of the gaming system.
- List of common/habitual file extensions (`.nes`, `.sfc`, `.md`, `.bin`, `.cue`, `.iso`, `.chd`, `.gba`, `.z64`, etc.).

## Planned Changes

1. **`src/core/system-info.ts` (NEW)**:
   - Create a dedicated domain module containing system metadata and logo SVG definitions for all supported systems (NES, SNES, Game Boy, GBC, GBA, N64, Pokemon Mini, Master System, Game Gear, Mega Drive, Mega CD, 32X, Saturn, PlayStation, TurboGrafx-16, TurboGrafx-CD, Neo Geo, Neo Geo CD, Atari 2600/5200/7800/Lynx, WonderSwan, WonderSwan Color).
   - Export helper function `getSystemInfo(folderOrSystemName: string): SystemInfo | undefined`.

2. **`src/components/SystemDetails.tsx` (NEW)**:
   - Component rendering system logo, title, manufacturer badge, release year, media format, system description, common file extensions list, and folder facts.

3. **`src/components/RomDetails.tsx`**:
   - Accept `folder?: string` prop in `RomDetailsProps`.
   - When no ROMs or games are selected (`paths.length === 0` and `!game`), if `folder` is present, render `SystemDetails` for the selected folder/system instead of the fallback empty state.
   - If `folder` is not recognized as a specific system (e.g. root or generic folder), render a generic folder information card.

4. **`src/views/ROMExplorer.tsx`**:
   - Pass `folder={folder}` to `<RomDetails />`.

5. **`src/styles/index.css`**:
   - Add responsive, premium CSS styling for `.system-details`, `.system-hero`, `.system-logo`, `.system-meta`, `.system-extensions`, and `.extension-tag` supporting both light and dark themes.
