## Proposed Terms and Categories

### Core Domain Concepts
1. **Game (Base Title)**: A single game entry representing all regional and revision releases of a game for a given System (e.g., "Super Mario World").
2. **Variant (ROM Variant)**: A specific release or version of a Game defined by DAT metadata (differentiated by region, language, revision, or media tags, e.g., `USA`, `Europe (En,Fr,De)`, `Rev 1`).
3. **System**: A supported hardware platform or retro console (e.g., `Nintendo - SNES`, `Sony - PlayStation`), identified by its canonical folder name.
4. **Medium**: The physical media type of a System (`cartridge` vs `disc`), which dictates the on-disk file layout.
5. **Consolidate / Normalize (File Consolidation / Normalization)**: The process of renaming and reorganizing ROM files into canonical naming conventions and folder structures according to their Medium and DAT match.

### Dataset & Identification
6. **DAT (Data Access Tool File)**: Reference database (No-Intro, Redump) containing canonical ROM checksums (CRC32, MD5, SHA-1) and standardized titles.
7. **Romset**: A set of multiple member files or chip dumps forming a single game entity (e.g., Neo Geo / Arcade ZIP archives), identified by the combined hashes of its member files.
8. **Intake / Intake Flow**: The process of adding or dropping raw/unconsolidated ROM files into a system directory for scanning, hash-matching, and placement.

### Storage & Organization
9. **Metadata Layer (`.meta/`)**: The system folder where non-ROM metadata, cover art cache, scan cache (`scan.json`), and folder preferences (`wizard.json`) reside.
10. **Cover Art**: Box art image associated with a Game and Region (EU, US, JP), fetched from repositories or added locally.
11. **Plan / Operation Plan**: A two-phase process preview showing intended file moves/renames before any disk modification occurs.

### UI & Navigation
12. **Explorer Modes**:
    - **Flat Mode**: Raw file system view showing actual directories and un-grouped files.
    - **Wizard Mode**: Grouped view showing recognized ROMs organized into games and variants (one row per Game).
13. **Curated Collection**: User-created custom folder or list of ROMs that the manager explicitly ignores to avoid altering user customizations.
