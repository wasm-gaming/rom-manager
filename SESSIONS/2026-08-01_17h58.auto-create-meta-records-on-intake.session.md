# Auto-Create `.meta` Records on ROM Intake Match

Date: 2026-08-01 17:58

## Summary
When ROM files are added to the library via intake (`RomIntakeService.apply`) and have been matched by checksum (`item.match` / `item.crc32`), automatically create their corresponding `.meta/<System>/<Game>.json` library record. This ensures games recognized by checksum automatically receive the green `.tree-badge` status indicator.

## Planned Changes

1. **`src/services/RomIntakeService.ts`**:
   - In `RomIntakeService.apply`:
     - After copying/extracting the ROM file for an `item` that has an `item.match` (or `item.crc32`), write a `.meta/<System>/<Game>.json` sidecar record using `RomLibrary`.
     - Populate `RomRecord` with metadata from `item.match` (`title`, `crc32`, `addedAt`, `updatedAt`) and enrich with `ROMDatasetService.lookupByCrc` metadata (such as `description`, `region`, `videoStandard`, `cover`) when available.

2. **`src/services/RomIntakeService.test.ts`**:
   - Add unit tests verifying that when intake items with a checksum match are applied, their sidecar `.meta/<System>/<Game>.json` file is created on the storage node.
