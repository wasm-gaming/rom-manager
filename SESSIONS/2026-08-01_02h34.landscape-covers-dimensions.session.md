# Session: Landscape Cover Dimensions

Date: 2026-08-01 02:34

## Objective
Set landscape cover wrapper width to match the height of portrait covers (240px).

## Problem Analysis
- Portrait covers (3:4 aspect ratio) with width 180px have a height of `180px * (4 / 3) = 240px`.
- Currently, landscape covers (e.g. SNES, GBA, N64 4:3 box art) defaulted to `width: 180px`, resulting in a tiny height of ~135px and reduced visual presence.
- Setting landscape cover width to 240px matches the 240px height of portrait covers, maintaining consistent visual prominence in the details hero section (`.rom-info-hero`).

## Proposed Changes
1. **`src/components/RomDetails.tsx`**:
   - In `CoverFigure`, parse `currentRatio` to detect if the aspect ratio is landscape (`width > height`).
   - Add `landscape` modifier class to `.rom-info-cover-wrapper` when landscape.

2. **`src/styles/index.css`**:
   - Add rule `.rom-info-cover-wrapper.landscape { width: 240px; }`.
