# Reopen Last Selected Folder On Reload

**Date:** 2026-08-01 01:42
**Topic:** Show a button to open the last selected folder on page reload instead of "Select a ROM to view its details"

## Context

When reloading the page with a previously opened FSA folder, stored handles are restored from IndexedDB with `locked: true`. Because browser security requires a user gesture to grant FSA handle permissions, `activeNode` remains `undefined` until the user re-authorizes access.

Currently, when `activeNode` is `undefined`, the `<FileTree>` is not rendered and `<RomDetails>` renders `<div class="empty-state">Select a ROM to view its details</div>` in the middle of the screen.

## Goal

Instead of showing "Select a ROM to view its details" when an open folder is locked on reload:
1. Show a prominent center action button to open/authorize the active (last selected) folder.
2. Persist and restore the last selected active tab ID in `localStorage` so reloading restores the active tab selection.

## Planned Changes

- Update `StoreService.ts` / `ROMExplorer.tsx` to persist `activeOriginId` in `localStorage` and restore it when handles are loaded.
- Update `ROMExplorer.tsx` to render a locked folder state card with a button `Abrir «[Nombre]»` whenever `activeOrigin?.locked` is true.
