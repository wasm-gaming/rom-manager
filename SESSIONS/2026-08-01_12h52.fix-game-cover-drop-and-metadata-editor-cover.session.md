# 2026-08-01 - Fix Game Cover Drop and Metadata Editor Cover Management

## Goal
1. Fix error (`errors.noGame`) when dropping a cover image onto a selected game/file in non-grouped folders (such as `Modern/MegaPang_v0.3_beta.bin`).
2. Make the cover section visible in `MetadataEditor` even when no cover currently exists, and allow adding/changing cover images via both Drag & Drop and File Picker (`<input type="file">`).

## Proposed Changes

### 1. `src/views/ROMExplorer.tsx`
- Update `dropDestination()`: when `game` is undefined but `selection` has a single file selected (`selection.length === 1`), infer a game target (`kind: 'game'`, `title: record?.title || gameNameOf(path)`, `folder: parentOf(path)`) and game metadata (`id: record?.id || gameNameOf(path)`, `system: systemOf(path)`).
- Update `handleSave` in `ROMExplorer.tsx` to handle an optional pending cover `File` or cover removal flag passed from `MetadataEditor`.

### 2. `src/views/ROMExplorer/MetadataEditor.tsx` & `src/views/ROMExplorer/RomDetails.tsx`
- Refactor cover rendering in `MetadataEditor`:
  - Always render the cover group/section, regardless of whether `previewUrl` exists.
  - If no cover exists or when hovering with dragged images, render a drop target zone allowing drag & drop of image files.
  - Add a file picker button connected to a hidden `<input type="file" accept="image/*">` for selecting local cover image files.
  - Provide preview of newly selected/dropped local cover images before saving.
  - Allow removing or changing existing covers.
- Update `onSave` callback signature to accept optional cover `File` or `coverRemoved` status.

### 3. Internationalization (`src/messages/es.yaml` & `src/messages/en.yaml`)
- Add translation keys for cover editor actions:
  - `editor.changeCover`: "Cambiar carátula" / "Change cover"
  - `editor.dropCoverOrClick`: "Arrastra una imagen aquí o haz clic para elegir una carátula" / "Drag an image here or click to select a cover"

## Walkthrough

- **`src/views/ROMExplorer.tsx`**: Updated `dropDestination()` to infer a game drop target when a single file is selected in non-grouped folders, preventing the `errors.noGame` error when dragging cover images. Extended `handleSave` to persist cover file additions or removals when saved from the metadata editor.
- **`src/views/ROMExplorer/MetadataEditor.tsx`**: Always renders the cover section, providing a drag & drop zone, a file picker button (`<input type="file">`), immediate image preview, and change/remove options.
- **`src/views/ROMExplorer/RomDetails.tsx`**: Propagated cover file upload and cover removal parameters to `onSave`.
- **`src/messages/es.yaml` & `src/messages/en.yaml`**: Added `changeCover` and `dropCoverOrClick` translation keys.
- **`src/styles/index.css`**: Added styles for `.cover-editor-group`, `.cover-drop-zone`, and `.cover-actions`.
