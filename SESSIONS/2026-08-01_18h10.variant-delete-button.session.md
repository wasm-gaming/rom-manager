# Add Delete Button to Variant Details

Date: 2026-08-01 18:10

## Summary
Add a delete button to variant rows in the game details view (`RomDetails.tsx`), allowing users to delete individual files or entire variants directly from the details pane. Deletion is confirmed via a `ConfirmModal` popup dialog.

## Planned Changes

1. **`src/messages/es.yaml` and `src/messages/en.yaml`**:
   - Add translation strings for deleting variants and variant files (`deleteVariant`, `deleteFile`, `deleteTitle`, `deleteMessage`, `deleteFileTitle`, `deleteFileMessage`).

2. **`src/views/ROMExplorer/RomDetails.tsx`**:
   - Add `onRemove?: (paths: string[]) => void` prop to `RomDetailsProps`, `GameView`, and `VariantRow`.
   - In `VariantRow`:
     - Render a delete button (`TrashIcon`) in the variant header when present files exist for that variant.
     - Render a delete button on each present file row in `variant-files`.
     - Clicking a delete button opens `ConfirmModal` to ask for user confirmation before calling `onRemove`.
   - Include `ConfirmModal` within `RomDetails.tsx` to handle confirmation popups.

3. **`src/views/ROMExplorer.tsx`**:
   - Pass `handleDeleteFiles` callback as `onRemove` prop to `<RomDetails />`.
   - `handleDeleteFiles` removes the target file(s) from `activeNode`, deletes sidecar metadata using `RomLibrary.remove(path)`, notifies tree via `handleRemoved(paths)`, and bumps `refreshToken`.

4. **`src/views/ROMExplorer/RomDetails.test.tsx` (or tests)**:
   - Add/update unit tests to verify the delete button appears for present variants and calls `onRemove` upon confirmation.
