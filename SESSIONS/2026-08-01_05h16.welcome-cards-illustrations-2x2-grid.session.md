## Context & Objectives

The landing page (`WelcomePanel`) displays four core capabilities under `.welcome-cards`:
1. **Hash (`hash`)**: Automatic No-Intro / Redump DAT identification by SHA-1 header checksum.
2. **Grouping (`grouping`)**: Grouping regional releases (EU/US/JP), revisions, and languages under unified game entries.
3. **Covers (`covers`)**: Local cached cover art integration from libretro-thumbnails.
4. **Consolidate (`consolidate`)**: Safe preview-first canonical file organization without data loss.

To improve visual impact and clarity:
- Add a custom vector illustration to each card representing its feature.
- Arrange the 4 cards in a 2x2 grid on desktop/tablet viewports, with responsive single-column layout on smaller screens.
