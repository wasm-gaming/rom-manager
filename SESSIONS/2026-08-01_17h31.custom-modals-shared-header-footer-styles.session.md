# Custom Modals & Shared Header/Footer Modal Styles

Date: 2026-08-01 17:31

## Objective
1. Replace native browser dialogs (`window.confirm`, `window.prompt`, `window.alert`) with custom accessible HTML `<dialog>` modal components.
2. Unify and standardize header (`.modal-header`) and footer (`.modal-actions` / `.modal-footer`) styles across all application modals (`PreferencesModal`, `MediaDropModal`, `RomIntakeModal`, `MetadataEditor` lookup modal, and new `ConfirmModal` & `PromptModal`).

---

## Planned Changes

### 1. Reusable Modal Dialog Components
- Create `ConfirmModal.tsx` and `PromptModal.tsx` (or generic `Modal.tsx`) using native `<dialog class="modal-dialog">` with proper accessibility (`aria-label`, focus management, escape key handling, backdrop click dismiss).
- `ConfirmModal`: Renders title, confirmation message / details, cancel button, and confirm (e.g. danger/delete) action button.
- `PromptModal`: Renders title, text input field pre-populated with suggested value, cancel button, and submit action button.

### 2. Update `FileTree.tsx`
- Remove `window.prompt('Directory name:', suggested)` in `handleCreateFolder`.
- Remove `window.confirm(...)` in `handleDeleteSelected`.
- Introduce state for managing prompt modal (new folder name) and confirmation modal (deletion of selected paths).

### 3. Standardize `MetadataEditor.tsx` Lookup Modal
- Convert the lookup modal in `MetadataEditor.tsx` from custom `.lookup-modal-overlay` div wrapper to standard `<dialog class="modal-dialog">`.
- Ensure structure strictly uses `.modal-header`, `.modal-content`, and `.modal-actions`.

### 4. Shared CSS Modal Header & Footer Styling (`src/styles/index.css`)
- Ensure `.modal-header` has consistent padding (`1.25rem 1.5rem`), background (`var(--surface-2)`), title font sizes, and close button (`.modal-close`).
- Ensure `.modal-actions` / `.modal-footer` has consistent flex placement (`justify-content: flex-end`), gap (`0.75rem`), border top (`1px solid var(--border)`), background (`var(--surface-2)`), and button styles (`.btn-apply`, `.btn-cancel`, `.btn-danger`).
- Ensure backdrop, animations, border radius, and box shadows are uniform across all modals.
