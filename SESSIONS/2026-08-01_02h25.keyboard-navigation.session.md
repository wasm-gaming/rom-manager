# Session: Enable Arrow Key Navigation in File Tree

Date: 2026-08-01 02:25

## Objective
Enable navigating the file tree using arrow keys when no text input or control is focused:
- `Up`: previous game/file row in the tree
- `Down`: next game/file row in the tree
- `Left`: parent folder (or collapse folder if expanded)
- `Right`: first child if exists (or expand folder if collapsed)

## Problem Analysis
Currently, navigating the ROM file tree requires mouse interaction or manual clicking. To improve keyboard accessibility and quick browsing of ROM collections, arrow keys should allow seamless tree navigation when text fields (like search bars, metadata textboxes, or modal inputs) are not focused.

## Proposed Changes
1. **`src/components/FileTree.tsx`**:
   - Add a global `keydown` event listener via `useEffect`.
   - Ignore keydown events when focus is inside an `<input>`, `<textarea>`, `<select>`, or contenteditable element (`document.activeElement`).
   - Intercept `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight` and prevent default scrolling behavior.
   - Implement navigation handlers:
     - `ArrowUp`: Move selection to the previous visible row (`rows[currentIndex - 1]`). If no selection exists, select `rows[0]`.
     - `ArrowDown`: Move selection to the next visible row (`rows[currentIndex + 1]`). If no selection exists, select `rows[0]`.
     - `ArrowLeft`: If current selection is an expanded directory, collapse it. If current selection is a file/group or a collapsed directory, select its parent directory.
     - `ArrowRight`: If current selection is a collapsed directory, expand it and select its first child if present. If current selection is an expanded directory, move selection to its first child.
   - Ensure newly selected tree item is scrolled into view (`scrollIntoView({ block: 'nearest' })`).

## Verification Plan
1. Test keyboard navigation with arrow keys:
   - Up/Down keys moving selection across files and folders.
   - Right key expanding folders and selecting first child.
   - Left key collapsing folders and moving focus to parent folder.
2. Verify arrow keys do NOT hijack typing when an input field (e.g. metadata editor, intake modal, search) is active.
3. Run existing test suite (`npm test`).
