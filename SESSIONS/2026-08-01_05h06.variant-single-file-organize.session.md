# 2026-08-01 05:06 - Single Variant File Consolidation via Organize Button

## Summary
Restructure the behavior of `.tree-organize` buttons on individual variant file rows in `RomDetails` so that clicking a variant's organize button only generates a consolidation plan for that specific variant's file, rather than all unorganized files in the system folder.

## Planned Changes

1. **`src/core/rom-organize.ts`**:
   - Add and export `filterPlanForPath(plan: OrganizePlan, targetPath: string): OrganizePlan` helper function to filter moves, conflicts, and markers of an `OrganizePlan` down to a specific target file path (or sub-path).

2. **`src/views/ROMExplorer.tsx`**:
   - In `handleOrganize(path: string)`:
     - Check if `path !== system` (meaning the request is for a specific file/sub-path, such as a variant file from `RomDetails`).
     - If `path !== system`, apply `filterPlanForPath` to the generated `OrganizePlan` before setting the organize state.

3. **`src/core/rom-organize.test.ts`**:
   - Add unit tests for `filterPlanForPath` verifying single file plan filtering for cartridge and disc variants.

## Verification Plan

- Run unit test suite `npm test`.
- Verify `.tree-organize` on variant files in `RomDetails` only targets the selected file while folder-level organize buttons continue to plan for the entire folder.
