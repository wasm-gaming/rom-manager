# Session: Split .tree-item into Left Content & Right Actions with Left Toggle & Fix Folder Details View

**Date:** 2026-08-01 05:43 (Extended 05:45)  
**Topic:** File Tree Item Layout & Folder Selection View Resolution

## Objectives
1. Split `.tree-item` element layout into 2 distinct sections:
   - **Left section (`.tree-item-left`)**: Contains the expand/collapse caret, row icon, and label/name.
   - **Right section (`.tree-item-actions`)**: Contains status icons, badges, group toggle buttons, and organize action buttons.
2. Update interaction behavior so clicking anywhere on the left section (`.tree-item-left`) toggles directory expansion (if expandable) in addition to selecting the row, instead of only the caret being clickable for toggle.
3. Fix folder selection details view in `RomDetails.tsx`:
   - When selecting a wizard folder (grouped by game), display full system details (`SystemDetails` with `wizard={true}`).
   - When selecting a normal folder (without wizard enabled), display generic folder details (`SystemDetails` with `wizard={false}`), eliminating the option to add folder as a ROM record / to the library.
